# SOS Colombia — guía de emergencia offline

App de emergencia para Colombia: llama al 123, guía primeros auxilios, ficha médica
que viaja en el aviso por WhatsApp, checklist del hogar y plan familiar. Funciona **sin
internet** (service worker), no crea cuentas, no sube datos: todo se queda en el teléfono.

**Usarla:** https://sebascontigo.github.io/sos-colombia/  ·  se puede instalar desde el menú del navegador (\"Añadir a pantalla de inicio\").
**Versión servida:** 4.5.0 · caché sos-colombia-v28.

**No edites este repo a mano.** El fuente vive en el proyecto ColombAI
(`ColombAI_SOS_Colombia/cosas/C-001-web-emergencia`) y aquí solo llega lo verificado por
`node dev/publicar_github.mjs`, que comprueba SHA-256 contra el fuente y deja la evidencia.

Gratis y sin ánimo de lucro. Fuentes del contenido: UNGRD, Cruz Roja Colombiana,
Defensa Civil, MinSalud, IDEAM, Servicio Geológico Colombiano.
